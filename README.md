# EmoVid-Movie

## Project Description

EmoVid-Movie is a multimodal emotion recognition project based on movie clips. The objective is to recognize eight emotions using three different modalities: text, audio, and video.

## Emotions

The project focuses on eight emotions:
- Amusement
- Anger
- Awe
- Contentment
- Disgust
- Excitement
- Fear
- Sadness

## Methodology

The project explores machine learning and deep learning approaches for each modality. It also investigates multimodal fusion techniques to combine information from text, audio, and video and improve emotion recognition performance.

## Project Structure

The repository is organized into four main parts:
- **Text:** Text-based emotion recognition.
- **Audio:** Audio-based emotion recognition.
- **Video:** Video-based emotion recognition.
- **Fusion:** Combination of the different modalities.

## Objective

The main goal is to compare individual modality models and multimodal fusion approaches for movie emotion recognition.
