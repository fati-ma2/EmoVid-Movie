# Audio – Speech (Parole)

## Objectif
Cette partie consiste à analyser les informations audio liées à la parole afin de contribuer à la reconnaissance des émotions dans les vidéos.

## Démarche
- Prétraitement des données audio.
- Extraction des caractéristiques vocales.
- Utilisation de modèles pré-entraînés.
- Entraînement et évaluation des modèles de classification des émotions.

## Résultats
Les résultats des modèles seront ajoutés après les expérimentations.
